# 🐍 Python Learning Journey

A personal collection of practice files, exercises, and experiments built while learning the Python programming language from the ground up.

---

## 📌 About This Repository

This repo documents my hands-on learning process with Python. Every file here represents a concept I explored, a problem I solved, or a pattern I practiced. It's not a polished project — it's a notebook, a scratchpad, and a record of progress.

---

## 🗂️ What's Inside

The files in this repo cover the foundations of Python, including:

- **Variables & Data Types** — integers, floats, strings, booleans
- **Control Flow** — `if`, `elif`, `else`, loops (`for`, `while`)
- **Functions** — defining, calling, parameters, return values
- **Data Structures** — lists, tuples, dictionaries, sets
- **File Handling** — reading and writing files
- **Modules & Imports** — using built-in and third-party libraries
- **Error Handling** — `try`, `except`, `finally`
- **Object-Oriented Programming** — classes, objects, inheritance

---

## 🎯 Goal

To build a strong foundation in Python by writing code every day, making mistakes, and learning from them. Mastery comes from practice, not just reading.

---

## 🚀 How to Run Any File

Make sure Python is installed, then:

```bash
python filename.py
```

To check your Python version:

```bash
python --version
```
